Chapter 3

Variables and Scope

Names are introduced with let, changed with =, and visible only inside the block that declares them.

Declaring and assigning

A name is letters, digits and underscores, and cannot start with a digit. The thirteen keywords listed in Appendix B cannot be used as names.

let creates a variable. = changes one that already exists. Assigning to a name that was never declared is an error, which catches typos that would otherwise silently create a new variable.

Assignment is an expression: it produces the assigned value, and chains from right to left.

Blocks

A pair of braces is a block, and every block is a new scope. Variables declared inside disappear when the block ends. A block can stand on its own, and it is also what follows if, while and fn.

Shadowing

An inner block may declare a variable with the same name as an outer one. The inner name hides the outer one until the block ends; the outer variable is untouched.

Reaching outward

Without let, an assignment finds the nearest enclosing variable of that name and changes it.

CarefulThe difference between let total = ... and total = ... inside a block is the difference between a new variable and changing the old one. Inside a loop body, a stray let gives you a fresh variable on every pass.

Scope follows the text

Lumen is lexically scoped. A function sees the variables that were visible where it was written, not the ones visible where it is called.

This one rule is what makes closures, the subject of chapter 7, work.
