Four ways to run code

CommandWhat it does
lumenStarts the interactive prompt (the REPL).
lumen file.lmRuns a script.
lumen -c 'print 6 * 7'Runs a program given as a string.
lumen -Runs a program read from standard input. Piping into plain lumen does the same.
lumen --versionPrints the version. -V is the short form.
lumen --helpPrints usage. -h is the short form.

The interactive prompt

Run lumen with no arguments to explore the language one entry at a time.

  • While a { or ( is still open, the prompt changes to ... and keeps reading. That is how multi-line blocks are entered.
  • A bare expression is evaluated and its value echoed, unless the value is nil.
  • Everything you define stays defined. An error reports and returns you to the prompt.
  • Arrow keys edit the line and recall history, which is saved in ~/.lumen_history between sessions.
  • Ctrl-C abandons a half-typed entry. Ctrl-D exits.

Exit codes

CodeMeaning
0The program ran to completion.
1A syntax or runtime error occurred, or the file could not be read. The message is on standard error.
2The command line itself was wrong. Usage is printed.

What happens when you run a program

Lumen reads the whole program before running any of it. A syntax error anywhere in the file therefore stops the program before its first line executes.
