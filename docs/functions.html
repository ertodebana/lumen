Chapter 6

Functions

Functions package up behaviour. In Lumen they are also ordinary values: they can be stored, passed to other functions, and returned.

Declaring and calling

return ends the function and hands back a value. A function that reaches the end of its body, or uses return with nothing after it, gives back nil.

A call must supply exactly as many arguments as the function has parameters.

Functions are values

The word fn without a name creates a function on the spot. In fact fn area(...) {...} is only a shorter way of writing let area = fn(...) {...}.

Recursion

A function may call itself. Every recursive function needs a case that does not recurse, or it will never finish.

Functions can also call each other, in either order, because a name is looked up when the call happens, not when the function is written.

The depth limit

Calls may nest 10,000 deep. Beyond that the program stops with a clear error instead of crashing.

NoteThere is no tail-call optimisation, so a loop that runs more than 10,000 times should be a while, not a recursion.
