Appendix C

Limits and Known Gaps

What Lumen 0.2.0 does not do, stated plainly, with the usual way around each.

LimitDetail and workaround
No lists or mapsFunctions are the only compound value. Build structures from closures, as in chapter 7.
No string indexingStrings can be joined, compared and measured, but not sliced or searched.
No break, continue or forPut the loop in a function and return; see chapters 5 and 11.
No error handlingA runtime error ends the program. Check first and return nil; see chapter 9.
No inputA program cannot read the keyboard, files or its command-line arguments.
No modulesA program is one file.
Call depth of 10,000No tail-call optimisation. Use while for long repetition.
Number literalsNo exponent form; a digit is required on both sides of the point.
Whole numbers above 253All numbers are 64-bit floats, so very large whole numbers lose exactness.
One error at a timeOnly the first syntax error in a file is reported.
Leading minusA line beginning with - continues the previous line; see chapter 10.
Ctrl-C while runningInterrupting a running program ends lumen, including the interactive prompt.
MemoryThere is no garbage collector. A closure stored in the scope it captured is not freed until the program exits.
Prompt line numbersIn the interactive prompt, line numbers in errors count from the start of the current entry.
