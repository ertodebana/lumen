Chapter 12

Embedding in Rust

The interpreter is also a Rust library, so a Rust program can run Lumen code and read the results.

Running code

Add the crate as a dependency, create an Interpreter, and call run. Global variables and functions persist from one run to the next, exactly as they do in the interactive prompt.

The API

ItemPurpose
Interpreter::new()An interpreter whose print writes to standard output.
Interpreter::with_output(f)An interpreter that hands each printed line to the closure f instead.
interp.run(source)Runs source text. Returns Ok(Some(value)) if the last statement was an expression, Ok(None) otherwise, or Err(LumenError).
ValueA Lumen value: Nil, Bool, Num, Str, Fn or Builtin. It implements Display the way print shows it.
LumenErrorEither Syntax(LumenSyntaxError) or Runtime(LumenRuntimeError). Both carry line and message.
SessionThe prompt's line-by-line logic: feed(line) returns None while brackets are open, then the result of the whole entry.
tokenize, parseThe lexer and parser on their own, for tools that inspect programs without running them.
run_on_big_stack(f)Runs f on a thread with a 256 MiB stack.

Capturing output

CarefulThe interpreter recurses on the native stack. A deeply recursive Lumen program can exhaust a default-sized thread stack before it reaches the 10,000-call limit, which aborts the host process. Wrap the work in lumen::run_on_big_stack(|| ...), as the lumen command does.
