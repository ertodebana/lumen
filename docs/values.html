Chapter 2

Values and Types

Lumen has five kinds of value. Variables do not have types; the values in them do.

TypeWritten asNotes
number42  3.14One numeric type: a 64-bit float.
string"hello"Text in double quotes.
booleantrue  falseThe result of comparisons.
nilnilThe absence of a value.
functionfn(x) { return x }A value like any other. See chapters 6 and 7.

Numbers

There is no separate integer type. Whole numbers are exact up to 9,007,199,254,740,992 (253), and a number with no fractional part prints without a decimal point.

A number literal is digits, optionally followed by a point and more digits. There is no exponent form, and .5 and 5. are not numbers; write 0.5 and 5.

Strings

Strings are written in double quotes and may contain four escape sequences.

EscapeProduces
\na new line
\ta tab
\"a double quote
\\a backslash

The + operator joins strings. If only one side is a string, the other side is converted to text first, which is how "total: " + 42 works. That is also the way to turn any value into a string: add it to "".

NoteStrings cannot be indexed or sliced, and there is no way to take one apart character by character. len and + are the string operations.

Booleans and nil

true and false come from comparisons and the logical operators. nil is what you get from a variable declared without a value, or from a function that does not return anything.

Truthiness

Any value can be used as a condition. The rule is short: only false and nil are falsy. Everything else counts as true, including zero and the empty string.

Equality

== and != work on any two values and never raise an error. Values of different types are never equal, and nothing is converted to make them match.

Two function values are equal only when they are the very same function.
