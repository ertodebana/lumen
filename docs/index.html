Lumen 0.2.0

Documentation

Lumen is a small, dynamically typed language with closures and first-class functions. It is not fast. These pages teach it from the first program to the full grammar.

Install

You need a Rust toolchain. Chapter 1 covers the command line and the interactive prompt.

Contents

Chapter 1Getting StartedInstall the interpreter, run a first program four different ways, and get comfortable in the interactive prompt. Chapter 2Values and TypesLumen has five kinds of value. Variables do not have types; the values in them do. Chapter 3Variables and ScopeNames are introduced with let, changed with =, and visible only inside the block that declares them. Chapter 4OperatorsArithmetic, comparison and logic, and the order in which they are applied. Chapter 5Control FlowTwo statements steer a program: if chooses, and while repeats. Chapter 6FunctionsFunctions package up behaviour. In Lumen they are also ordinary values: they can be stored, passed to other functions, and returned. Chapter 7ClosuresA function remembers the variables that were in scope where it was created, and keeps them alive. That single idea gives Lumen private state, configurable functions, and even data structures. Chapter 8Built-in FunctionsTwo functions are available everywhere without being declared. Chapter 9ErrorsWhen Lumen cannot continue, it says what went wrong and on which line. There are two kinds of error, and they happen at different times. Chapter 10Lines and LayoutLumen has no statement terminator. A handful of rules about line breaks make that work, and each is worth knowing once. Chapter 11RecipesShort, complete programs for common jobs. Each one runs as printed. Chapter 12Embedding in RustThe interpreter is also a Rust library, so a Rust program can run Lumen code and read the results. Appendix AGrammarThe complete syntax, in EBNF. Braces mean "zero or more", square brackets mean "optional", and a bar separates alternatives. Appendix BQuick ReferenceThe whole language on one page. Appendix CLimits and Known GapsWhat Lumen 0.2.0 does not do, stated plainly, with the usual way around each.
