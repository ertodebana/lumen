Rules to remember

  • Only false and nil are falsy.
  • + joins when either side is a string.
  • Different types are never ==.
  • let declares; = needs an existing name.
  • Braces are required; conditions take no parentheses.
  • One statement per line, or separate with ;.

Command line

lumen                 start the interactive prompt
lumen file.lm         run a script
lumen -c CODE         run a program passed as a string
lumen -               run a program read from standard input (also when input is piped)
lumen -V, --version   print the version
lumen -h, --help      print usage

exit codes            0 success    1 Lumen error or unreadable file    2 bad usage
