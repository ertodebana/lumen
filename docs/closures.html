Chapter 7

Closures

A function remembers the variables that were in scope where it was created, and keeps them alive. That single idea gives Lumen private state, configurable functions, and even data structures.

A function that remembers

make_counter has returned, yet count lives on, because the function it returned still refers to it. Each call to make_counter creates a new count, so a and b count separately. Nothing outside can reach either count except through its function.

The variable, not a copy

A closure holds the variable itself. If the variable changes later, the closure sees the new value.

Configured functions

A function that takes a setting and returns a function is a cheap way to make a family of related functions.

Private state

A closure can guard its data and decide what is allowed. Here the balance can only be changed through the function, and the function refuses to overdraw.

Data from closures

Lumen has no lists. A closure that remembers two values is enough to build one: each cell holds an item and the rest of the list, and nil marks the end.

Everything in this program is functions and closures: the list cells, the operations on them, and the squaring function handed to map.
